# AutumnAUTools

## 绩点与目标成绩计算器

React 版首页快捷入口或悬浮球导航进入，路由为 `/#/gpa`。

- 按课程学分加权计算 GPA，支持直接录入绩点或自定义百分制分段换算；百分制初始规则只是示例。
- P / N / EX 自动排除；非空课程编号相同的记录取最高绩点；其他不计入课程手动取消勾选。
- 使用课程明细，或直接填写已有 GPA 与学分，反推剩余课程所需平均绩点，提示不可达目标。
- 按平时成绩、期末占比反推所需期末分数，提供整数分门槛。
- 自动保存到本机浏览器，支持导出文字结果。清空、删除和示例替换支持撤销。

计算口径参考[本科生院 2026-07-16 说明](https://jwc.cau.edu.cn/art/2026/7/16/art_41139_1122721.html)，课程归属、替代和排名口径需按个人情况核对。

验证：在 `app/` 下运行 `pnpm test:gpa`（Node.js 22.6+，使用内置 TypeScript 类型剥离）和 `pnpm build`。
